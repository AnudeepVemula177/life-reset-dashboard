# Life Reset Dashboard V2
Responsive productivity dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Updated desktop and mobile UI
- Pomodoro timer with 25, 15 and 5-minute presets, pause/resume and reset
- Focus time tracking
- Add, complete, delete and clear tasks
- Daily habit checklist, progress percentage and streak display
- Accent colour switch
- Local browser saving with localStorage

## Publish on GitHub Pages
Replace the existing `index.html`, `style.css`, `script.js`, and `README.md` in your repository with these four files. Then open **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and click **Save**. Wait a few minutes for deployment.

## Learn the files
- `index.html`: content and structure
- `style.css`: appearance and responsive layout
- `script.js`: timer, task actions, habits, progress and saving
- `localStorage`: saves on this browser/device; it does not sync automatically to other devices.
