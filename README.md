# Life Reset Dashboard

A beginner-friendly, dark futuristic productivity dashboard built with HTML, CSS, and JavaScript.

## Features in version 0.1

- 25-minute focus timer with pause and reset
- Add, complete, and delete daily tasks
- Daily task progress percentage
- Saves tasks in the browser using localStorage
- Responsive layout for laptop and mobile screens

## Run locally

1. Download or extract this project folder.
2. Open `index.html` in a web browser.
3. Add tasks and try the focus timer.

No installation or build tools are required.

## Project files

- `index.html` — page structure
- `style.css` — dark theme, layout, and responsive styles
- `script.js` — timer, task interactions, progress, and browser storage

## Publish with GitHub Pages

1. Create a GitHub repository named `life-reset-dashboard`.
2. Upload the contents of this folder (the three app files and README) to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The Pages section will show the live URL.

Note: browser localStorage is device/browser-specific; tasks do not automatically sync between devices.
