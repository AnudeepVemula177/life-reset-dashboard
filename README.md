# 🌌 Life Reset — Personal Command Center

A futuristic, responsive personal productivity dashboard built with HTML, CSS, and vanilla JavaScript.

## Features
- Neon purple-blue UI with an aqua accent theme switch
- Progress cards for completed tasks, daily progress, focus time, and streak
- Focus timer with 5-, 15-, and 25-minute presets, pause/resume, and reset
- Task manager: add, complete, delete, and filter All / Active / Completed
- Daily habit tracker with a progress bar
- Responsive layout for desktop and mobile
- Saves tasks, habits, focus time, and theme preference in this browser using `localStorage`

## Run locally
Keep `index.html`, `style.css`, and `script.js` in the same folder, then open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `life-reset-dashboard`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub Pages will show your public website URL in the Pages section.

## Project files
- `index.html` — dashboard structure
- `style.css` — neon theme, layout, and responsive styling
- `script.js` — timer, tasks, habits, progress, streak, and browser storage

## Notes
- Data is stored locally in the browser on the device you use. It does not sync between devices or browsers.
- Motivational music is intentionally left for a later phase, after the UI and core features are finalized.
