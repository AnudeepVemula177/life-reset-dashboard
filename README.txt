LIFE RESET — Anime Physique bundle

Files:
- index.html
- style.css
- script.js

Setup:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or deploy all three files together to your existing static hosting.
3. Existing dashboard data is stored locally in this browser. Use Backup before replacing any live files.
4. The Anime Physique module stores its settings and workout log in localStorage.

This is a starter fitness planner, not medical advice. The plans use general bodyweight/basic gym ideas and should be adjusted for injuries, health conditions, and individual ability.
